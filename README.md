# member-register

ระบบตรวจสอบคุณสมบัติสมาชิกและการเข้าร่วมนมัสการ · คริสตจักรคอร์เนอร์สโตน หัวหิน
จัดทำระบบโดย มน.สมเจต เสมาทอง ประธานธรรมกิจคริสตจักร

## ⚠️ repository นี้เป็น Public

ไฟล์ที่อยู่ใน repository นี้เป็น **เวอร์ชันสาธิต** เท่านั้น — ชื่อสมาชิกถูกแทนด้วย "สมาชิกตัวอย่าง 001…501" และ **ไม่มี** เบอร์โทรศัพท์ วันเกิด รหัสสมาชิก หรือหมายเหตุ ใดๆ
คงไว้เฉพาะรูปแบบวันเวลาของการเข้าร่วมนมัสการ เพื่อสาธิตการคำนวณและการจัดลำดับ

**ห้ามอัปโหลดไฟล์ที่มีข้อมูลจริง** (`ทะเบียนผู้นมัสการ-ภายใน.html`, `data.js`, `data.enc.js`, ไฟล์ export จาก Google Sheet) ขึ้น repository นี้

## เกณฑ์ที่ระบบใช้ (ตามระเบียบปฏิบัติธรรมนูญคริสตจักรภาค 7)

- ขาดการนมัสการ **ครบ 1 ปี** → คณะธรรมกิจส่งผู้แทนหรือหนังสือไปตักเตือน (ข้อ 93.4(4))
- ยังคงขาดต่อไป **จนถึงสามปี** → เสนอพิจารณาให้พ้นจากการเป็นสมาชิกสมบูรณ์ แต่คงสถานภาพเป็นสมาชิกสำรองไว้ จนกว่าคณะธรรมกิจจะมีมติให้กลับเป็นสมาชิกสมบูรณ์อีกครั้ง
- สมาชิกสำรอง: ขาดครบ 1 ปี → ตักเตือน · ครบ 3 ปี → เสนอพิจารณาให้พ้นจากการเป็นสมาชิกสำรอง (ข้อ 94.6(4))
- **เกณฑ์วิเคราะห์เพิ่มเติม** อายุสมาชิกเกิน 1 ปี และมานมัสการเกิน 10 ครั้งใน 12 เดือนล่าสุด — ใช้เพื่อการวิเคราะห์และจัดลำดับเท่านั้น
- ผลในคอลัมน์ "ผลตรวจ" เป็นข้อมูลประกอบการพิจารณาของคณะธรรมกิจ **ไม่ใช่การเปลี่ยนสถานภาพทางทะเบียนอัตโนมัติ**
